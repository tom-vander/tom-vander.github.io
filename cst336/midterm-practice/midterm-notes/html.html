HTML Tags

Element Type Description Code
Headings Used to apply formatting that illustrates hierarchical structure within the content. <h1>Heading 1</h1>
Paragraphs Used to create a block of text that is separated from adjacent blocks of text <p>This is a paragraph</p>
Line Breaks Used to create a line break within a paragraph <br>
Images Used to embed an image within a document <img src="image.jpg" alt="Description of image">
Links Used to create a hyperlink that navigates to another page or resource <a href="https://www.google.com">Google</a>
Comments Used to add notes or explanations to a document <!-- This is a comment -->
Lists Used to create ordered or unordered lists of items <ul>
<li>Item 1</li>
<li>Item 2</li>
</ul>
Tables Used to create tabular data <table>
<tr>
<td>Cell 1</td>
<td>Cell 2</td>
</tr>
</table>
Division Used to group content within a document <div>This is a division</div>
Span Used to apply inline formatting to a portion of text within a document <span style="color: red;">This text is red</span>

HTML Styling

Element Description Code
Italics Used to apply italic styling to text <em>Italic Text</em>
Bold Used to apply bold styling to text <strong>Bold Text</strong>
Span Used to apply inline styling to text <span style="color: red;">Red Text</span>

HTML Selectors

Selector Type Description Code
Ids Used to select an element based on its unique identifier <div id="myDiv">...</div>
Classes Used to select elements based on their class attribute <div class="myClass">...</div>

Form Elements

Element Description Code
Form Used to create interactive forms that allow users to input data <form>...</form>
Input Used to create input fields that allow users to enter data into forms <input type="text" name="username">
Button Used to create buttons that trigger actions within a form <button type="submit">Submit</button>
Select Used to create dropdown menus that allow users to select an option from a list <select name="language">
<option value="en">English</option>
<option value="fr">French</option>
</select>
Text Area Used to create multi-line text input fields <textarea name="bio"></textarea>

Input Types

Input Type Description Code
Text Used to create text input fields <input type="text">
Password Used to create password input fields that mask the entered text <input type="password">
Email Used to create email input fields <input type="email">
Number Used to create numeric input fields <input type="number">
Date Used to create date input fields <input type="date">
Time Used to create time input fields <input type="time">
Range Used to create input fields that allow users to select a value from a range of values <input type="range" min="0" max="100">
Color Used to create color input fields <input type="color">
Checkbox Used to create checkbox input fields that allow users to select multiple options from a list <input type="checkbox" name="languages">
File Used to create file input fields that allow users to select files from their device <input type="file">
Radio Used to create radio input fields that allow users to select a single option from a list <input type="radio" name="gender">
