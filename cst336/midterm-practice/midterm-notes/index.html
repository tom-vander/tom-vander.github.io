Week 1 Assignments

Lab 1: ePortfolio Site
  • Create a site with three pages: Home, About, and Contact.
  • About page includes table, list, styles, footer
  • Contact page includes Google Form and styles
  • Footer has the CSUMB logo across all pages.
  • Footer font is smaller and a different color than Home page content.

HW 1: HTML and CSS
  • Create four web pages about any topic related to CS.
  • Navigation menu that links each page to each other.
  • Each page should include at least one graphic.
  • An external CSS file with at least 20 CSS properties.
  • Hyperlinks to the sources where you collected the information.

Week 2 Assignments

Lab 2: Guess the Number
  • All form elements are included: input and button
  • The list of player's attempts (guesses) per match is shown
  • A message says whether the last guess was high or low
  • A congratulatory message is displayed when guessing the number within seven attempts
  • If not, display a "You Lost" message in red and the random number.
  • An error message is displayed if a number is entered higher than 99.
  • The total number of games "won" and "lost" are shown and updated properly.
  • When finishing the game, hide or disable the "Guess" button and display a "Reset" button.
  • The web page has a nice design (uses at least 25 CSS properties)

HW 2: US Geography Quiz
  • Uses a variety of input types: checkbox, number, radio, select, text.
  • Feedback per question (correct/incorrect) is displayed properly.
  • An image indicating whether the answer is right or wrong is displayed.
  • Radio buttons and checkboxes are accessible (use the "label" tag).
  • Multiple choices are displayed in random order (for at least one question).
  • The total score is displayed and calculated properly (100 pts in total).
  • The total times the quiz was taken used Web Storage
  • Congratulatory message is displayed if the score is above 80.
  • It uses Bootstrap and has a nice look and feel.

Week 3 Assignments

Lab 3: Sign Up Page
  • City, Longitude, and Latitude are updated when entering a zip code.
  • A "Zip code not found" message is displayed next to its textbox, if that's the case.
  • The list of countries is updated properly when selecting a State.
  • Upon typing the username, a color-coded message indicates whether it is available or not
  • Upon clicking on the password text box, a suggested password is displayed next to it.
  • When the page loads, the list of all US states is displayed in the dropdown menu
  • Page uses Bootstrap or includes 20 CSS rules

HW 3: Fetch and Web APIs
  • There is at least one form element for user's input
  • There is JS validation for at least one form element (e.g. length, range, not empty, etc.)
  • There is at least one event listener
  • There is at least one fetch call
  • Data is retrieved from an existing Web API
  • Web API data is displayed on the page in a user-friendly format
  • There is an external CSS file with at least 10 rules
