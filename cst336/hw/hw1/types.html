Malware Description
Adware Displays specific advertisements to users and retrieves user data for further target purposes
Backdoor Points of entry within systems or programs that bypass security measures
Bots Unapproved remote access to infected computers that allow attacker control over them
Computer Virus Programs that replicate their code into other programs when it's executed
Keyloggers Unsupervised recording of keystrokes made by the user of an infected system
Ransomware Denies users access to their infected systems to encourage them to pay a ransom
Rootkits Gives attackers root access to infected computer systems, giving them administrator level control
Spyware Discreetly gathers user and system information overtime and relays it to attacker
Trojan Horses Malicious software disguised as a genuine program
Worms Programs that replicate their code into other programs without being executed
